# Grocery Basket Probe

Технический прототип для проверки одной гипотезы: можно ли получать публично доступные адресные предложения «Перекрёстка» с низкой частотой и без обхода технических ограничений.

Это **не** пользовательское приложение и не готовый парсер. До положительного отчёта в [`docs/source-investigation/perekrestok.md`](docs/source-investigation/perekrestok.md) запрещено реализовывать автоматизированный коннектор к источнику.

## Границы первого спринта

- один ретейлер: «Перекрёсток»;
- три заранее заданных тестовых адреса Москвы и МО;
- до 100 массовых SKU для технической проверки;
- read-only сбор только данных, доступных без аккаунта, SMS, CAPTCHA bypass, мобильных токенов и обхода rate limits;
- результат: нормализованные предложения и наблюдения цен, экспортируемые в JSON/CSV.

Не входит: оформление заказа, оплата, пользовательские аккаунты, карты лояльности, фотографии, длинные описания, matching между сетями и фронтенд корзины.
