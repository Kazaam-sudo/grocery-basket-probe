# Prompt 02: recommendation basket MVP

Ты работаешь в репозитории grocery-basket-probe.

## Контекст

Мы создаём рекомендательный веб-сервис для Москвы и Московской области. Он
сравнивает полную корзину между Пятёрочкой, Магнитом и Лентой и помогает перейти
к выбранной сети. Сервис не оформляет заказы и не переносит корзины через
внутренние API.

## Задача

Подготовь архитектурный каркас для вертикального среза без live-парсинга:

1. Добавь доменные модели basket item, normalized offer, basket quote и
   retailer handoff.
2. Добавь use case расчёта subtotal по сети на заранее сохранённых fixtures.
3. Добавь классы результата `exact`, `equivalent`, `substitute`, `unknown`.
4. Добавь генератор handoff-представления:
   - публичный URL сети;
   - список с названием, упаковкой и количеством;
   - CSV/JSON экспорт.
5. Добавь unit-тесты на цену, количество, неизвестную цену, пропущенный товар и
   повторяемость расчёта.

## Ограничения

- не выполнять HTTP-запросы к сетям;
- не добавлять авторизацию, оплату или интеграцию с корзиной ритейлера;
- не считать неизвестные fees нулевыми без явного флага;
- не использовать LLM как единственный механизм matching;
- не изменять схему источника без миграции и теста.
