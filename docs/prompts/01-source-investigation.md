# Prompt 01 — техническая разведка публичного каталога Перекрёстка

Работай в репозитории `Grocery Basket Probe`. Перед началом прочитай полностью:

- `README.md`;
- `docs/technical-prd.md`;
- `docs/architecture.md`;
- `docs/source-investigation/perekrestok.md`.

## Цель

Не писать коннектор и не менять прикладной код. Провести read-only техническую разведку: можно ли получить публичные адресные предложения «Перекрёстка» для ограниченного теста без обхода защит.

## Разрешённые действия

1. Открыть обычную публичную веб-витрину без авторизации.
2. Использовать не более трёх заранее согласованных тестовых адресов; не записывать их полный текст в репозиторий, логи или отчёт.
3. Проверить вручную или с редкими read-only запросами:
   - выбор адреса без аккаунта;
   - наличие публичного ID зоны или магазина;
   - различие каталога, цены или наличия для адресов;
   - поиск 20 массовых товаров;
   - доступность названия, упаковки, цены, типа цены, наличия, URL и публичного product ID;
   - HTML/структурированный публичный запрос, пагинацию, необходимые consent cookies;
   - работу при частоте не выше 6 запросов в минуту.
4. Заполнить таблицу наблюдений и итог в `docs/source-investigation/perekrestok.md`.

## Жёсткие запреты

- Не использовать логин, SMS, аккаунт, карту лояльности, токен мобильного приложения или чужие cookies.
- Не обходить CAPTCHA, 403/429, fingerprinting, rate limits или географические ограничения.
- Не использовать прокси-ротацию, browser-stealth, антикапчу или автоматическое оформление заказа.
- Не сохранять полный адрес, персональные данные, cookie headers, фотографии и длинные описания.
- Не писать production-коннектор, Playwright-автоматизацию или код массового парсинга.

## Когда остановиться

Немедленно остановись и зафиксируй `Stop`, если появляется CAPTCHA, SMS/login wall, закрытый токен, регулярные 403/429 при низкой частоте или явный запрет выбранного способа в условиях.

Зафиксируй `Pivot`, если данные видны человеку, но недостаточны или не удаётся устойчиво и допустимо установить адресный контекст.

Только при `Go` предложи — не реализуя — точный публичный путь, поля контракта и безопасную частоту для последующего review.

## Формат результата

Сделай один коммит только с изменением `docs/source-investigation/perekrestok.md`. В финальном сообщении дай:

1. статус Go / Pivot / Stop;
2. подтверждённые наблюдения с URL и временем;
3. список доступных полей;
4. что неизвестно;
5. рекомендацию следующего шага.

Не делай предположений о закрытых API и не выдавай предположения за подтверждённые факты.
