# Каскадный выбор товара

Основной сценарий теперь состоит из трёх обязательных шагов:

1. пользователь вводит категорию и выбирает её из списка;
2. затем выбирает бренд из вариантов этой категории;
3. затем выбирает фасовку из вариантов выбранного бренда.

Произвольную строку нельзя добавить через быстрый селектор. Текст используется только для фильтрации списка.

## Каталог

Каталог хранится в `web/data/product-catalog.json`. Сейчас в нём 57 карточек, включая
публичный снимок каталога «Перекрёстка» от 24 августа 2026 года. У каждой карточки есть:

- `category_id` и `category_label`;
- `brand`;
- `pack`;
- название товара;
- источник публичной карточки;
- дату проверки источника для карточек «Перекрёстка».

Основной источник нового снимка — публичные категории «Перекрёстка»:

- молоко;
- йогурты;
- яйца;
- сливочное масло;
- хлеб и выпечка;
- кофе.

По каждой карточке сохранены название, бренд, фасовка, категория, ссылка на открытую
страницу источника и дата проверки. Это реальные товарные варианты, а не придуманные
названия.

Важно: цены и наличие по-прежнему относятся к демонстрационному снимку, а не к live-каталогу
магазина. Следующим отдельным этапом будет read-only-коннектор с адресным обновлением
цен и наличия; добавлять такие данные прямо в статический JSON нельзя, иначе они быстро
станут устаревшими.
