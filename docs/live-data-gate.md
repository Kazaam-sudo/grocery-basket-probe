# Live data gate

**Дата проверки:** 21.08.2026

Этот документ фиксирует границу между демонстрационными данными и настоящим
источником цен. Статический GitHub Pages-интерфейс не ходит на сайты торговых
сетей напрямую: для live-данных нужен отдельный read-only ingestion job или
легитимный публичный/партнёрский feed.

## Текущее решение

Статус: **Pivot до получения разрешённого источника**.

В текущей среде низкочастотные обращения к публичным витринам дали:

| Источник | Наблюдение | Решение |
|---|---|---|
| Перекрёсток | Публичная витрина перенаправляет к access-check/challenge | Stop; обход запрещён |
| Магнит | Ранее доступны публичные карточки и поиск, но адресная доставка требует входа; повторная проверка из текущей среды получила 403 | Нет production-коннектора; разрешена только новая разведка при публичном пути |
| Пятёрочка | Повторная проверка публичного каталога получила 403 | Нет production-коннектора |
| Лента | Повторная проверка каталога получила 401 | Нет production-коннектора |

Это не означает, что сети нельзя подключить в принципе. Это означает, что сейчас
нет подтверждённого публичного адресного endpoint, который можно безопасно
поставить в автоматический сборщик.

## Что уже добавлено в код

`PublicSourceProbe` выполняет ровно один обычный GET:

- без аккаунта, токенов, cookies профиля и прокси;
- без CAPTCHA bypass и browser-stealth;
- без повторов после 401/403/429 или timeout;
- без сохранения HTML или длинных описаний;
- с классификацией `available`, `blocked`, `unavailable`, `unknown`.

`available` означает только, что URL ответил публичным HTTP-ответом. До
подключения в корзину всё равно нужно отдельно доказать поля товара, адресный
контекст, наличие и повторяемость цены.

## Что нужно, чтобы перейти к live-данным

Подойдёт один из вариантов:

1. официальный публичный или партнёрский feed/API без пользовательского аккаунта;
2. разрешённый экспорт каталога от сети или агрегатора;
3. публичный URL JSON/CSV, который владелец данных разрешает обновлять по
   расписанию.

Для каждого источника должны быть подтверждены: товар, упаковка, цена, наличие,
URL, время наблюдения и связь с городом/зоной. Если источник требует login wall,
CAPTCHA, закрытый mobile token, обход rate limit или stealth-прокси, gate остаётся
в статусе `blocked`.

## Демонстрационный запуск

До зелёного gate UI продолжает работать на явно помеченном снимке
`web/data/demo-quotes.json`. Нельзя выдавать этот снимок за текущие цены и нельзя
смешивать его с live-наблюдениями без отдельной пометки источника.
