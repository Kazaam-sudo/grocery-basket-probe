# Source investigation: Магнит

**Статус:** частичный Go — публичный каталог, поиск, карточка и официальный
поиск магазинов доступны без авторизации. Публичная установка адреса именно для
доставки заблокирована login wall: после выбора режима «Доставка» сайт просит
войти в аккаунт. Это не обходится и пока не позволяет считать адресную доставку
подтверждённой для production-коннектора.

**Цель:** проверить, можно ли получить минимальный auditable-набор публичных
предложений без обхода защиты. Это не разрешение на массовый сбор или на
использование внутренних endpoint.

## Границы проверки

- 16.07.2026 проведено четыре read-only обращения к обычной публичной витрине:
  каталог, одна карточка, один поиск и повтор того же поиска;
- частота не превысила шести обращений в минуту;
- не использовались аккаунт, SMS, карта лояльности, мобильные токены, cookies
  профиля, CAPTCHA bypass, прокси или browser-stealth;
- не выполнялись добавление в корзину, заказ или оплата.

## Проверка публичных адресов Москвы

19.08.2026 официальный каталог магазинов принял и повторно обработал три
неперсональных адреса. В режиме «Списком» для каждого возвращалась одна и та же
структурированная строка магазина:

| Тестовый адрес | Результат публичного поиска | Публичный `shopCode` в карточке из индекса Магнита |
|---|---|---:|
| г Москва, ул Ивовая, д 6 к 2 | «Магнит у дома», 08:00–23:00 | `721711` |
| г Москва, ул Знаменские Садки, д 1А | «Магнит у дома», 08:00–23:00 | `770265` |
| г Москва, ул Мироновская, д 18 | «Магнит у дома», 08:00–23:00 | `774862` |

Публичные результаты поиска Магнита связывают эти адреса с карточками, в URL
которых передан соответствующий `shopCode`:

- [Ивовая, 6 к 2](https://magnit.ru/product/1000461011-magnit_slivki_u_past_10_500ml?catalogType=1&shopCode=721711&shopType=1);
- [Знаменские Садки, 1А](https://magnit.ru/product/4000045102-ugol_drevesnyy_2_5_kg?shopCode=770265&shopType=1);
- [Мироновская, 18](https://magnit.ru/product/1000290444-semena_lna_zdorovyy_stil_250g?shopCode=774862&shopType=1).

### Ограничение адресного режима

В штатном диалоге каталога режим «Доставка» переключается без CAPTCHA, но сразу
показывает «Войдите в аккаунт» и сообщает, что адреса берутся из аккаунта. Режим
«Самовывоз» позволяет без входа найти магазин по адресу, однако найденная строка
не содержит публичной кнопки, которая бы установила магазин как активный каталог.

Дополнительная проверка прямой страницы каталога с
`?shopCode=721711&shopType=1` оставила в видимом контексте магазин по умолчанию в
Краснодаре. Поэтому один только query-параметр `shopCode` нельзя считать доказанным
механизмом переключения адресного каталога; это требует отдельного технического
эксперимента с разрешённым публичным endpoint или партнёрским источником.

## Подтверждённый минимальный контракт

Публичная витрина способна отдать для отдельной карточки:

```text
retailer = magnit
source_product_id = часть URL после /product/
name = видимый заголовок
observed_price = видимая цена
regular_price / promotional_price = только когда это явно обозначено
quantity = извлекается из названия как неподтверждённая нормализация
source_store_id = shopCode, пока без подтверждённого соответствия адресу
url = публичная карточка
fetched_at = время наблюдения
availability = unknown
```

Нельзя подменять «Финальная цена», «+5% с Премиум» или кнопку «В корзину»
догадками о типе цены, персональной выгоде или наличии.

## Решение и следующий gate

**Частичный Go на продолжение разведки, но не Go на production-коннектор.**

Разрешён следующий ограниченный эксперимент только если появится легитимный
публичный или партнёрский способ задать delivery-context без аккаунта. Три
неперсональных адреса Москвы уже проверены через официальный поиск магазинов:

1. установить адресный delivery-context штатным публичным UI или документированным
   партнёрским способом;
2. не более шести read-only обращений в минуту;
3. сравнить одну и ту же выборку из 20 SKU по трём contexts;
4. проверить, как стабильно связать адрес, `shopCode`, цену и отсутствие товара;
5. остановиться при CAPTCHA, login wall, 403/429 или необходимости закрытых
   токенов.

До завершения gate запрещены массовый collector, scraping внутренних запросов,
прокси и реализация production-коннектора.
