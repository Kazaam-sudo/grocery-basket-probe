# Source investigation: Перекрёсток

**Статус:** Stop — публичная витрина недоступна для разрешённого автоматизированного технического теста.  
**Цель:** определить, доступен ли разрешённый публичный путь к адресным предложениям для ограниченного read-only технического эксперимента.

## Правила проведения

- только обычная публичная витрина и ручная/низкочастотная проверка;
- не использовать авторизованный профиль, SMS, мобильное приложение, сохранённые токены, CAPTCHA bypass, прокси или fingerprint rotation;
- прекратить проверку сразу при CAPTCHA, login wall, 403/429, явном запрете выбранного способа или потребности в закрытых данных;
- не выполнять добавление товара, оформление заказа или другие изменяющие действия;
- не сохранять полный адрес, cookies, заголовки авторизации и персональные данные.

## Наблюдение

При обычном неавторизованном открытии публичной поисковой страницы витрина не
вернула каталог, а перенаправила запрос на служебный маршрут проверки доступа.
Адрес редиректа содержал короткоживущие технические параметры; он намеренно не
сохранён в документе. На странице не было доступного каталога или предложения
выполнить обычный выбор адреса. Не использовались логин, SMS, cookies профиля,
мобильные токены, прокси, browser-stealth и любые средства обхода защиты.

Это техническое наблюдение, а не вывод о правомерности доступа к данным вообще.

## Решение

**Stop для запланированного public-catalog connector.** Система не может
продолжать разведку, потому что первый безопасный запрос уже потребовал
техническую проверку, а правила проекта запрещают её обход или решение.

Следующий допустимый путь — запросить у Перекрёстка/X5 официальный партнёрский
feed или API с письменными условиями использования. Альтернативно можно
проверить другого ритейлера тем же протоколом, но не возобновлять попытки
доступа к этой витрине без нового разрешённого канала.

## Формат вывода

В конце отчёта поставить один статус:

- **Go:** путь публичен, адресный, достаточен для теста и не требует обхода;
- **Pivot:** есть данные, но нет устойчивого/допустимого способа для прототипа;
- **Stop:** нужен обход ограничений или путь явно недопустим.

Только статус `Go` разрешает начать реализацию `connectors/perekrestok/`.
